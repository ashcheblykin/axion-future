# Axion Gen · Future vision

Кликабельная демонстрация концепта «агент‑центричный Axion» — по макету
[Figma · Axion Talks](https://www.figma.com/design/XDOceRokvyikE1cuk6HO9S/Axion?node-id=5414-188133)
и на дизайн‑системе `lens-vision/focus.html`. Чистые HTML + CSS + JS, без сборки и зависимостей.

```bash
node tools/serve.mjs 5320      # затем http://localhost:5320
```

Макет нарисован в 1920×1080 — на этом размере каждый бокс встаёт на координату из фрейма.
На других размерах это по‑прежнему раскладка, а не масштабированная картинка: ниже 1920 колонка
чата становится текучей (карточка инцидента и таймлайн перестраиваются под ширину), ниже 1600 и
1440 сужаются колонка виджетов и сайдбар, ниже 1320 виджеты уезжают в выдвижную панель (кнопка
Cards в хедере, Esc закрывает), ниже 1000 так же ведёт себя сайдбар (кнопка слева в хедере).
Сверять с макетом пиксель в пиксель имеет смысл в окне 1920×1080.

## Что внутри

| Маршрут | Что это |
|---|---|
| `#/chat/<id>` | чат с агентом внутри проекта; виджеты, которые агент открыл, — справа |
| `#/new` | новый тред: приветствие и подсказки |
| `#/library` | Library: таблица `axion_sense.frames`, панель кадра, фильтры, колонки, карта |
| `#/scheduled` · `#/signals` · `#/dashboards` · `#/users` · `#/settings` | остальные страницы |
| `#/focus` | Focus mode — живая страница Lens целиком |
| `?concept=agent` | agent‑centric раскладка (фрейм 4): без Gen Sidebar, AXION в сайдбаре, профиль внизу |

Живые части: виджеты «Riyard scene» и «Global KPIs» встраивают настоящую страницу Lens
(`lens/focus.html`, копия из lens-vision) в iframe — 3D‑захват Olaya Street (Gaussian splats) и
планета с пинами. Если WebGL недоступен, показываются кадры из макета. Орб Axi говорит через
`speechSynthesis` и слушает через `SpeechRecognition`, когда браузер их даёт; иначе разыгрывает
сценарий по тексту.

Клавиши: `⌘K` поиск · `⌘J` консоль агента · `⌘⇧A` голос · `⌘N` новый чат · `/` в поле ввода · `Esc` закрыть.

## Структура

```
index.html            каркас: рейл, сайдбар проектов, страницы
assets/css/tokens.css переменные дизайн‑системы (из Figma, тёмная тема)
assets/css/app.css    оболочка и общие атомы; далее по модулю на файл
assets/js/app.js      состояние, роутер, меню/поповеры/тосты/палитра, встраивание Lens
assets/js/data.js     весь контент демо
assets/js/{chat,widgets,timeline,library,pages,orb}.js
assets/icons/         Phosphor regular + спрайт (node tools/build-sprite.mjs)
assets/figma/         ассеты, выгруженные из макета
docs/SPEC.md          спецификация: геометрия, токены, контент, сценарии, контракты модулей
docs/figma/           четыре фрейма 1:1 для сверки
tools/shot.mjs        скриншот + ошибки консоли (Playwright из ../lens-vision/node_modules)
lens/                 копия focus.html из lens-vision со всеми ассетами (45 МБ)
```
